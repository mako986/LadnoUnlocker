# LadnoUnlocker

LadnoUnlocker — это легковесная и полностью автономная утилита на чистом C++ (Win32 API), предназначенная для экстренной диагностики и восстановления работоспособности системы Windows.

Проект разработан как инструмент "последней надежды" для ситуаций, когда вирусы, поврежденные политики или сбои в конфигурации блокируют доступ к стандартным средствам Windows (Диспетчер задач, Редактор реестра и т.д.).

## Основные возможности

*   **Управление процессами**: Просмотр и контроль активных процессов в системе.
*   **Диагностика автозагрузки**: Проверка ключевых параметров системного автозапуска.
*   **Сброс политик**: Восстановление доступа к Диспетчеру задач и Редактору реестра, заблокированных вредоносным ПО.
*   **Восстановление ассоциаций**: Исправление поврежденных связей файлов (exe, bat, cmd).
*   **Встроенный обозреватель**: Портативная навигация по файловой системе дисков.
*   **Управление службами**: Возможность запуска и остановки критических служб Windows.
*   **Планировщик задач**: Базовая диагностика и контроль системных задач.

## Преимущества

*   **Zero-Dependency**: Не требует .NET Framework, внешних библиотек или установки. Работает "из коробки" на любой версии Windows.
*   **Портативность**: Один исполняемый файл (~130 КБ).
*   **WinRE/WinPE Ready**: Идеально подходит для запуска из среды восстановления Windows через командную строку.
*   **Нативность**: Написан на чистом Win32 API, что обеспечивает максимальную стабильность и скорость работы.

## Сборка и запуск

1.  Откройте файл проекта в **Visual Studio 2022** (или новее).
2.  Выберите конфигурацию **Release** и архитектуру **x64**.
3.  Нажмите **Собрать решение (Ctrl+Shift+B)**.
4.  Исполняемый файл `LadnoUnlocker.exe` будет находиться в папке `x64\Release\`.

## Использование в экстренных ситуациях

Если система не загружается в нормальный режим:
1. Загрузитесь в **WinRE** (Среда восстановления).
2. Выберите: *Поиск и устранение неисправностей* -> *Дополнительные параметры* -> *Командная строка*.
3. Перейдите к расположению вашего `LadnoUnlocker.exe` и запустите его.
